1. DELETE /conteudos/{id}
A descrição retornada no statuscode 200 é diferente da esperada.
Retornada: O conteúdo foi removido com sucesso!
Esperada: Conteúdo removido com sucesso

A descrição retornada no statuscode 404 é diferente da esperada.
Retornada: Erro ao excluir o conteúdo, o conteúdo não foi encontrado.
Esperada: Conteúdo não encontrado



2. PUT /conteudos/{id}
O Request body de exemplo vem com dois campos que não deveriam existir, pois não são necessários para executar e gerando erro.
Request body de exemplo:
{
  "id": "string",
  "titulo": "string",
  "descricao": "string",
  "tipoConteudo": "string",
  "conteudo": "string",
  "dataCadastro": "2024-07-05T20:03:24.379Z"
}

Request body necessário para executar:
{
  "titulo": "string",
  "descricao": "string",
  "tipoConteudo": "string",
  "conteudo": "string"
}

A descrição retornada no statuscode 404 é diferente da esperada.
Retornada: O contedúdo que você está tentando alterar não existe na base de dados. ID INFORMADO: 20
Esperada: Conteúdo não encontrado


3. GET /conteudos/{id}
No valor de exemplo do retorno com statuscode 200 o id informado é do tipo string, mas no response body retorna o id com o tipo inteiro.

A descrição retornada no statuscode 404 é diferente da esperada.
Retornada: O conteúdo com o ID: 20 não foi encontrado.
Esperada: Conteúdo não encontrado



4. GET /conteudos
No valor de exemplo do retorno com statuscode 200 o id informado é do tipo string, mas no response body retorna o id com o tipo inteiro.
